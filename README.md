# Оформление документов Е. В. Бэкман

Навык (skill) для Claude, который оформляет все документы по требованиям Е. В. Бэкман: файлы Word (.docx), Google Docs, тесты, билеты и методические материалы.

## Требования

- Шрифт Times New Roman, 14 пт во всём документе.
- Межстрочный интервал одинарный.
- Абзацный отступ первой строки 1,25 см.
- Интервалы перед абзацем и после абзаца 0, без пустых строк.
- Основной текст выровнен по ширине, название по центру.
- Жирным выделяется только название документа.
- Поля: верхнее и нижнее 2 см, левое 2,5 см, правое 1,5 см.

Для тестов навык задаёт формат названия, строку с инструкцией, сплошную нумерацию вопросов, пять вариантов ответа с одним правильным, ключ в конце и равномерное распределение правильных ответов по буквам.

## Как установить

1. Скачайте папку с файлом `SKILL.md` (или весь репозиторий архивом ZIP).
2. В Claude откройте Settings → Capabilities → Skills и загрузите навык.
3. После этого Claude применяет требования ко всем документам автоматически.
