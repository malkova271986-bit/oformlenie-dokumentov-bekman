# Оформление документов Е. В. Бэкман

Эти требования применяются ко всем документам, которые я создаю или правлю для пользователя: файлы Word (.docx), Google Docs, тесты, билеты, методические материалы. Отступать от них можно только если пользователь в конкретной просьбе прямо сказал иначе.

## Основные требования

- Шрифт: Times New Roman во всём документе, включая заголовок, варианты ответов, ключ, таблицы и подписи.
- Размер: 14 пт везде.
- Межстрочный интервал: одинарный (1,0).
- Абзацный отступ первой строки: 1,25 см.
- Интервалы перед абзацем и после абзаца: 0. Никаких пустых строк и дополнительных пробелов между абзацами.
- Выравнивание основного текста: по ширине. Название документа: по центру.
- Выделение: жирным только название документа (например, «Test on Pedagogy: Lectures 1-6 (Variant 1)»). Всё остальное без жирного, курсива и подчёркивания, если пользователь не попросил иначе.
- Поля страницы: верхнее и нижнее 2 см, левое 2,5 см, правое 1,5 см.

## Тесты

- Название в формате «Test on <дисциплина>: <лекции> (Variant N)», затем строка «Instructions: choose one correct answer for each question.».
- Вопросы идут подряд с одной нумерацией 1–20, без названий лекций и разделов внутри документа.
- У каждого вопроса 5 вариантов: A) … E), ровно один правильный.
- В конце «Answer key» и строка вида «1 - B; 2 - D; …».
- Правильные ответы распределены равномерно по буквам (при 20 вопросах по 4 на каждую букву).
- Вопросы распределяются равномерно по лекциям и берутся из материалов лекций пользователя.

## Как задавать оформление технически

- docx (библиотека docx для Node): шрифт `Times New Roman`, `size: 28`; у абзацев `spacing: { before: 0, after: 0, line: 240 }`, `indent: { firstLine: 709 }` (1,25 см), `alignment: JUSTIFIED`; у названия `alignment: CENTER`, `bold: true`, без отступа первой строки; поля `top: 1134, bottom: 1134, left: 1418, right: 850`.
- Google Docs через HTML: `p { margin:0; padding:0; font-family:'Times New Roman',serif; font-size:14pt; line-height:1.0; text-indent:1.25cm; text-align:justify }`, у названия `text-align:center; text-indent:0` и `<b>` только в названии.
- После создания файла проверить: один шрифт, один размер 14, жирный только в названии, нет пустых абзацев.
